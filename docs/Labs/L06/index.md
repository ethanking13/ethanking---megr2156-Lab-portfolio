# A6 – Design Fits for an Artifact

# Parametrically Design

## 1. What are the parameters used?

The main parameters used in my CAD model were length, width, and height. These dimensions controlled the overall size of my snap-fit design.

## 2. Why did you choose the specific parameters?

I chose these parameters based on the measurements I took from the artifact. The dimensions helped ensure that my design would fit properly into the existing feature and create a secure snap fit. I also chose them so I could easily adjust the dimensions if the fit was too loose or too tight.

## 3. What values did you choose for the specific parameters?

The initial values I chose for my CAD model were:

- Length: 783 thou
- Width: 5925 thou
- Height: 985 thou

These values were based on the measurements I took from the artifact and were used as the starting dimensions for my design.

## 4. Did the values change throughout the process? If so, why?

Yes, I made adjustments to some of the dimensions throughout the design process to improve the fit. I wanted to make sure the part would snap securely into the artifact without being too loose or too tight.

## 5. Take measurements of the needed feature of the artifact.

I measured the feature of the artifact using a caliper to determine its length, width, and height. These measurements were used as a reference when creating my CAD model to ensure the snap-fit design would fit properly into the artifact.
